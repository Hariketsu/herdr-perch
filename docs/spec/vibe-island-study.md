# Vibe Island 真机研究（2026-10-20）

资料来源：用户手动录制的 `ref/vibe-island/`，包括两段录屏（8s 和 16s，按 pt 录制，24fps）和两张设置页截图。动画数据是逐帧测量形状尺寸得到的。官网首页的网页演示与真机不一致，**以真机为准**。

## 1. 动画

| 项 | 真机表现 | Perch 现状（bc33bdc） |
|---|---|---|
| 尺寸 | 收起 220×38 → 展开 655×160。展开进度依次为 25%、56%、72%、88%、94%、98%（每帧 42ms），约 0.35s 稳定，过冲 < 1% | 近临界阻尼 spring，曲线基本吻合 |
| 收起 | 高度约 0.33s 收完，宽度尾巴约 0.6s，不下冲 | 0.3s，不下冲；宽度没有更长的尾巴 |
| 内容 | 只做 opacity，从形状变化的第一帧开始，约 125ms；不缩放；收起时被收缩的形状裁切的同时淡出 | 一致 |
| 收起态元素 | 展开时立刻淡出；收起时在收起开始就淡入 | 两耳固定、始终可见（区别见第 2 节） |
| 顶部图标 | 收起时最先淡出（第 1～2 帧） | 无（齿轮在列表底部） |
| 宠物 | Working 时有逐帧跑动的像素动画，并按状态换色 | Blocked 时跳动；Idle 时闭眼 |

## 2. 布局

- **收起态非常窄**：默认的 Clean 模式只有"左耳宠物 + 右耳一个数字"（约 220pt 宽）；Detailed 模式才在耳朵里显示会话标题和状态。
- **展开态的顶部那一条**（菜单栏高度）：左边空着，右边是两个图标按钮（静音、设置）。收起态的宠物会"进入"列表行，作为每个会话的图标。
- **展开态更宽**：约 655pt（设置里 Max Panel Width 默认 640pt），我们是 400pt。
- **列表行是圆角卡片**：宠物图标，标题为"项目 · 会话标题"，第二行是"You: 最后一句话"，第三行是 Agent 最后回复的摘要，右侧是 Agent 标签（彩色）、终端标签和时长。
- **其他卡片**：
  - 顶部提示卡（例如"Enable precise jump for Kitty"，带 Enable 按钮和关闭按钮）；
  - 完成卡（"You: …"加回复内容，带 Done 标记，可滚动）；
  - 底部的付费入口卡。

## 3. 交互

- hover 展开、移开收起，与 Perch 一致。
- Agent 完成时会自动展开并显示完成卡片，内容来自 hooks。Perch 只能显示"✓ 标题"（已确认）。

## 4. 设置（Display 页）

| 分组 | 项 |
|---|---|
| Notch | 实时预览；Clean / Detailed 两种收起样式；显示器选择 |
| Panel size | 内容字号；完成卡高度（90pt）；最大面板高度（560pt）；最大面板宽度（640pt） |
| Session card | 是否显示：项目名、worktree、Agent 图标、终端图标、AI 模型、推理强度、任务清单、子 Agent、Agent 活动详情；附实时预览卡 |
| Tuning | 刘海宽度、高度微调（0 = 使用 macOS API 报告的值） |

其他设置页（未截图）：General、Integrations、Notifications、Sound、Usage、Shortcuts、SSH Remote、Labs。

## 5. Perch 可以借鉴的（按价值排序）

1. 收起态默认更窄，只有"宠物 + 数字"，给菜单栏留出空间。这也缓解了 Ice 的遮挡问题。
2. 展开态更宽（约 560～640pt），并把面板宽度和高度做成设置。
3. 收起时宽度的尾巴比高度更长。
4. 顶部那一条放图标按钮（设置），收起时最先淡出。
5. Working 时宠物播放逐帧跑动动画（用 Core Animation 实现，避免 CPU 开销）。
6. 设置页加入收起态和会话卡片的实时预览。
7. 刘海尺寸微调。

不可行或不做的：

- "You: 最后一句话"、回复摘要、任务清单、子 Agent：需要 hooks 或读屏。
- 付费卡、SSH、用量统计：超出 Perch 的范围。
